# 프로젝트 08 — 어절 검수 도구

현재 기준 스크립트는 `audit_latest.py`입니다. Google Sheets에서 내려받은 XLSX를 읽어 기계적으로 판정 가능한 어절·하이라이트 형식 오류를 찾습니다. 원본 파일이나 검수 결과 데이터는 이 폴더에 저장하지 마세요.

## 최신 검수 기준

- 원문을 공백 단위로 나눈 결과와 어절 행을 비교합니다. Unicode 문장부호와 공백을 제거해 비교하며, 문장부호만 있는 어절 행은 앱 미사용 데이터로 보고 오류 검사 전체에서 제외합니다.
- 동일한 어절들이 다른 순서로 놓여 있으면 누락·추가가 아니라 `어절 순서 오류`로 분류합니다.
- 원문 대비 실제 어절 개수 차이는 `어절 누락`, `어절 추가`, `어절 중복`으로 구분합니다. 대체·철자 변형이 섞인 경우 기계적으로 확정할 수 없으므로 보고서의 누락·초과 후보를 확인해야 합니다.
- 어절 셀 내부 공백을 별도로 표시합니다.
- 하이라이트가 비어 있거나, 원문 그대로 해당 어절 안에 포함되지 않으면 표시합니다. 하이라이트의 의미상 적절성은 판단하지 않습니다.
- 숫자로 저장되며 앞자리 0이 사라진 값(예: 원문 `0000`, 시트 값 `0`)은 알려진 시트 자동 변환으로 간주해 토큰 오류에서 제외하고 메타데이터에 기록합니다.

이 검사는 어절 정렬·형식 검수이며 문맥, 표제어·품사·사전 뜻, 하이라이트 의미 범위, 구 병합의 정확성은 판정하지 않습니다. 대상 탭에 문장 행이 하나도 남지 않은 경우도 외부 원문 목록 없이는 감지할 수 없습니다.

## 실행 방법

Python 3.9 이상, 표준 라이브러리만 사용합니다. `review2`가 포함된 탭을 자동 선택하며, 탭 이름이 다르면 `--sheet-name`으로 지정합니다.

```bash
python audit_latest.py "/path/to/sheet-export.xlsx" \
  --output-dir "/path/to/audit-output" \
  --source-sheet-url "https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit?gid=SHEET_ID"
```

출력 폴더에는 `audit_latest_report.json`(행·문장 단위 사례)과 `audit_latest_meta.json`(집계, 제외 항목, 입력 SHA-256)이 생성됩니다. 보고서에는 시트 행과 `문장_토큰_ID`를 포함하며, 링크를 만들려면 원본 탭 URL을 전달하세요. 같은 출력 폴더로 다시 실행하면 결과를 덮어쓰므로 실행별 폴더를 권장합니다.

## 입력 형식

XLSX 내부 탭 이름과 열 제목을 읽어 대상 탭을 찾습니다. 필수 열은 `콘텐츠_SN`, `콘텐츠_유형`, `문장_순서`, `문장`, `어절_순서`, `어절`, `하이라이트_텍스트`이며 `문장_토큰_ID`는 있으면 결과에 함께 표시합니다. 첫 행은 헤더여야 합니다. 이전 버전처럼 특정 `sheetN.xml` 번호나 고정 열 순서에 의존하지 않습니다.
